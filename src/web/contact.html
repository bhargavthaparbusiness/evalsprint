Contributions

Pull requests are welcome. The README explains how to set up the project and which checks must pass.

Contributing guide

Security issues

Please don't post exploit details in a public issue. Open an issue that says you have a security report, without the details, and the maintainer will arrange a private way to share it.

Privacy questions

See the Privacy Policy first. For anything it doesn't answer, open an issue. GitHub issues are public, so don't include personal or sensitive information.

Email

No dedicated contact email has been set up for this project yet. GitHub Issues is the supported contact channel.
